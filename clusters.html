Methodology & Data Sources

DATA SOURCES (priority order):
1. Helius Enhanced Transactions API — primary source for swap decoding and wallet history
2. Solana RPC — token supply verification and fallback queries

CLUSTERING METHODOLOGY:
- Analyzed top 200 holders + 200 traders per token
- Wallets appearing in both sets flagged for deeper analysis
- Early entry defined as: first 15 minutes OR first 300 swap events
- Trade reconstruction via enhanced transaction parsing (Helius)
- P&L calculation: FIFO cost basis, realized gains only
- Exit quality: ROI >= 3x + 70% position exit before 50% drawdown

CLUSTERING HEURISTICS:
- Temporal proximity (entry/exit synchronization)
- Transaction pattern similarity (frequency, size, timing)
- Shared DEX venues and router preferences
- Jito tip usage patterns (latency arbitrage indicator)
- Cross-wallet funding relationships (where detectable)

LIMITATIONS:
- 100 txn limit per wallet query may miss historical context
- Off-chain funding sources not visible
- Private transactions or direct transfers not fully captured
- Price data relies on DEX pool ratios at transaction time

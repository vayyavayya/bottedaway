Methodology

METHODOLOGY (per specification):

1. DATA SOURCES (priority order):
   A) Helius Enhanced Transactions API — primary for swap decoding
   B) Birdeye / Solscan — attempted but unavailable
   C) Solana RPC — attempted but unavailable

2. HOLDER × TRADER INTERSECTION:
   - "Holders": Wallets with token account ownership (inferred from accountData)
   - "Traders": Wallets with swap/transfer activity (inferred from tokenTransfers)
   - Analysis limited to wallets appearing in BOTH sets

3. EARLY ENTRY DEFINITION:
   - First 15 minutes OR first 300 swap events
   - Time delta calculated from token's first recorded swap

4. EXIT QUALITY CRITERIA:
   - ROI >= 3x AND 70%+ position exited
   - Exit before 50% drawdown from local peak (heuristic)
   - Top quartile timing within first 48h

5. LIMITATIONS:
   - Brand new tokens (Feb 26, 2026) — limited historical data
   - Holder APIs returned incomplete data
   - Transaction count limited to 100 per wallet query
   - Price data estimated from DEX pool ratios at tx time
